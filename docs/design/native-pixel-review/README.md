## 補景與輪廓差異

- 從確認過姿態的 480 × 270 平常地景開始，在三處地標原址局部補畫。新筆觸、路端及植被輪廓均落在 1× 整數格線上，紋理採同張地景的原生像素與取樣色。補景在局部改變了山稜、樹形、草叢與道路末端，石橋、河流、瀑布和主路的其餘部分沿用原地景。
- 角色取自對應的 1× 平常與抬手地景，沿用之前逐行描繪的兩張審稿遮罩並校正木框柱腳。可對照舊素材檢查髮絲、手部、腿部與靴底的深色輪廓，以及角色和木框之間的透明空隙。
- 已目視核對純背景、兩種原位合成及三種底色，並檢查各圖尺寸、原生像素座標、遮罩透明度與保留像素顏色。純背景及第一組地標確認後，再處理展示館與信箱，提交疊有介面的完整首頁對照。
