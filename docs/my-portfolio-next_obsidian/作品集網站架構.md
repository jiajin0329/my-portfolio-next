# 作品集網站架構

開啟 [[作品集網站架構.canvas|作品集網站架構 Canvas]] 查看程式架構與首頁地圖導覽。

## 檔案對照

| 要調整的內容 | 從專案根目錄查看 |
| --- | --- |
| 頁面語言、SEO metadata、樣式載入 | `src/app/layout.jsx` |
| 首頁區塊順序、關於我、技能、工作經驗、聯絡區與頁尾 | `src/components/PortfolioApp.jsx` |
| 頂部導覽與手機選單 | `src/components/Navbar.jsx` |
| 首屏介紹、像素地圖、地標連結與展示館櫥窗 | `src/components/AdventureHero.jsx` |
| 作品卡片、影片播放與關閉、職責展開 | `src/components/ProjectCard.jsx` |
| 共用區塊標題 | `src/components/SectionHeading.jsx` |
| 個人資料、導覽項目與作品清單 | `src/data/portfolio.js` |
| YouTube 影片 ID 解析 | `src/lib/video.js` |
| 字體、色彩與間距變數 | `src/styles/typography.css` |
| 全域樣式、焦點與減少動態偏好 | `src/app/globals.css` |
| 地圖、面板、卡片與響應式版面 | `src/components/PortfolioApp.css` |
| 地圖預覽、背景與地標圖檔 | `public/images/adventure/` |

## 首頁導覽圖

三個地標都以首頁內的錨點連結跳轉。信箱入口會先到聯絡區，使用者再點選 Email 連結開啟郵件程式。

首頁閱讀順序為導覽列、冒險地圖、關於我、技能與技術、作品展示館、工作經驗、聯絡我、頁尾。頁尾的「回到地圖」連回 `#home`。
